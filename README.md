Praca inżynierska - projekt i implementacja aplikacji do monitorowania przyjmowania leków z funkcją powiadamiania opiekuna. Aplikacja pozwala na łączenie dwóch użytkowników, z czego jeden jest "Administratorem", zaś drugi jest "Użytkownikiem". Administrator modyfikuje listę leków, otrzymuje powiadomienia. Użytkownik zaznacza przyjęcie leków.
